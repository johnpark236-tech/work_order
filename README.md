# 작업오더 — 자동화 설비 공수·견적 관리 (MVP)

스마트폰에서 매일 작업일지를 **선택형**으로 기록하고, 부품 → 조립체 → 설비 대수 → 설비 → 프로젝트 공수 집계와 턴키 견적서까지 만드는 웹앱입니다.
특정 설비·제조사·고객사 이름은 들어 있지 않으며, 실제 명칭은 사용자가 직접 입력합니다.

## 접속

GitHub Pages: `https://johnpark236-tech.github.io/work_order/`
(저장소 Settings → Pages → Branch `main` / `/ (root)` 로 켜야 열립니다.)
스마트폰 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있고, 한 번 열면 통신이 끊겨도 동작합니다.

## 사용법

1. **프로젝트** 탭 — 프로젝트명 입력, 설비 수량·설비 대수 선택 → 구조 자동 생성. 이름 변경·추가·삭제·구성 복제 가능.
2. **일지** 탭 — 부품명만 입력하고 나머지는 버튼 선택: 프로젝트·설비·설비 대수·조립체·공정·볼트 규격·길이·너트(없으면 `없음`)·와셔·공구·수량·볼트 1개당 조립시간·인원·준비·검사·대기·재작업.
   - 같은 부품명을 다시 쓰면 지난번 선택값을 자동으로 불러옵니다.
   - 같은 볼트·너트 조합의 실측 평균 시간을 제안합니다.
   - 버튼에 없는 값은 `＋`로 추가하면 다음부터 버튼으로 나옵니다.
   - 날짜별 조회, 전날 일지 가져오기, 텍스트 복사, 엑셀(CSV) 받기.
3. **집계** 탭 — 설비 › 설비 대수 › 조립체, 공정별, 일자별 공수와 표준공수(실측·신뢰도), 확인이 필요한 기록.
4. **견적** 탭 — 실측 공수·대기율·재작업률을 자동으로 채우고 일당·경비·이익률을 선택 → 예상 원가, 위험 포함 원가, 최소 수주가, 권장 견적가, 이익률. 저장한 견적은 PDF(인쇄)·엑셀(CSV)로 출력.
5. **설정** 탭 — 작업자·상호, 선택 항목 관리, 백업 파일 받기/불러오기.

## 계산식

```
반복작업 인분 = 수량 × 개당 작업시간(분)
순공수(인분)  = 준비 + 반복 + 검사
공수(MH)      = 순공수 ÷ 60
대기·재작업   = 시간(분) × 인원  → 순공수와 별도 집계(중복 합산 없음)
예상 소요시간 = 순공수 ÷ (인원 × 협업효율) + 대기 + 재작업
견적가        = (직접비 + 간접비 + 대기·재작업 위험) ÷ (1 − 목표 이익률)
```

예: M8×25 24개 × 0.8분 = 19.2인분, 준비 12 + 검사 6 → 37.2인분 = 0.62 MH

## 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `css/style.css` | 화면 |
| `js/calc.js` | 공수·표준공수·견적 계산 엔진 |

저장 데이터 구조: `projects[ equipment[ modules[] ] ]`, `records[]`(작업기록), `estimates[]`(입력값·결과·표준공수 스냅샷 포함), `settings`(선택 항목·협업효율).

## 현재 범위와 한계

- 데이터는 **각 기기의 브라우저**에 저장됩니다. 다른 사람·다른 기기와 공유되지 않습니다(백업 파일로 이동 가능).
- 로그인, 회사별 데이터 분리, 역할 권한, 승인·변경 이력은 아직 없습니다. GitHub Pages는 서버가 없어 이 기능에는 별도 백엔드(예: 인증 + PostgreSQL)가 필요합니다.
- 음성 기록, AI 자동 분류는 2차 범위입니다.
- 체결 토크는 다루지 않습니다. 승인된 도면·제조사 규격을 따르세요.
